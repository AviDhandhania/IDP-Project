Research and planning workspace for our year-long **Innovative Design Project** (3 people).

## The short version

- **Safest publishable result:** LLM unit-test generation (ULT) or Uncertainty-Gated Reasoning (UGR).
- **Most impressive + real-world:** Satellite remote sensing for environmental crime & disaster.
- **Most industry-relevant:** Malicious-package detection or prompt-injection defense.

Every idea is grounded in real 2025–2026 papers with a public dataset and a baseline to beat.
**Rule #1:** lock the baseline version at project start — those numbers move fast.
